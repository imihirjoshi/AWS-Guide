AWS CodeCommit

Developer Tools  ·  Advanced, most people never need it

AWS's own private Git repository hosting.

Picture it as

A filing cabinet in your own office rather than a shared one down the street.

What it actually does

CodeCommit stores Git repositories inside your AWS account with IAM controlling access. AWS closed it to new customers in 2024, then reversed that in late 2025 and made it generally available again with new features planned. It has no pull request review culture, issues, or actions comparable to GitHub or GitLab, so it is a bare repository host.

Reach for it when

  • Your rules say source code must stay inside your AWS account
  • You want repository access controlled by IAM roles, not separate accounts
  • You need a repo in a restricted region such as GovCloud

Do not reach for it when

  • You want code review, issues and a community, use GitHub or GitLab
  • Your CI already lives on GitHub, connecting AWS to it is easier than moving

One small example

A bank keeping its deployment scripts in an account that has no route to the public internet.

How you pay

Free for the first five active users per month, then a flat fee per active user, with extra for storage and requests above the included amount.
