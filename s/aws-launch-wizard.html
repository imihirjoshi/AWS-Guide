AWS Launch Wizard

Management and Governance  ·  Advanced, most people never need it

A guided form that builds the AWS setup for a few specific packaged applications.

Picture it as

The setup wizard on a new printer. It asks a few questions and does the fiddly bits for you.

What it actually does

You answer questions about size and availability, and it generates and deploys a CloudFormation stack sized for that application. It supports a short list, mainly SQL Server, SAP and Active Directory. It is narrow, and outside that list it is no help at all. What it produces is a normal stack you can then manage yourself.

Reach for it when

  • A first SQL Server Always On cluster on EC2
  • Standing up an SAP landscape without deep AWS knowledge

Do not reach for it when

  • Anything not on its short supported list, write CloudFormation or Terraform
  • Infrastructure your team will keep changing, own the templates from the start

One small example

A Windows admin answers ten questions and gets a highly available SQL Server cluster across two availability zones.

How you pay

The wizard is free. You pay for the EC2, storage and any Windows or SQL licensing it turns on, which is not small.
