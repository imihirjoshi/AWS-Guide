Amazon EFS

Storage  ·  Learn this early

A shared folder that many servers can read and write at the same time.

Picture it as

A filing cabinet in the middle of an office. Anyone can open a drawer, and everyone sees the same papers.

What it actually does

EFS is managed NFS storage. It grows and shrinks on its own, spans multiple availability zones, and mounts on EC2, ECS, EKS and Lambda. It is a network file system, so per file latency is higher than a local disk, and small random writes are noticeably slower. It is Linux only, there is no SMB support.

Reach for it when

  • Several machines need the same files, such as uploads or shared config
  • A web app you cannot rewrite that expects a normal filesystem
  • Lambda functions needing more than the small temp space

Do not reach for it when

  • For a single machine's fast disk, use EBS, it is cheaper and quicker
  • For Windows and SMB shares, use FSx for Windows File Server
  • For storing objects an app fetches by key, S3 costs far less

One small example

Three WordPress servers behind a load balancer all mount the same EFS volume so an image uploaded on one appears on the others.

How you pay

Per GB stored per month, with a standard and a cheaper infrequent access tier. The surprises are the per GB charge for reading infrequent access data, and Elastic throughput mode billing per GB transferred.
