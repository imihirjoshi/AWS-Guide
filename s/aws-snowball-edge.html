Basics / Services / Storage

AWS Snowball Edge

Storage  ·  Advanced, most people never need it

A rugged box AWS posts you, which you fill with data and post back.

Picture it as

Posting a hard drive instead of uploading over a slow line.

What it actually does

No longer available to new customers. AWS now points new users to DataSync for online copies, aws-data-transfer-terminal for physical drop off, and aws-outposts-family for edge computing. The device held large amounts of data, could run EC2 instances and Kubernetes offline, and shipped with an E Ink label. It is still supported for existing customers, but it is not something to plan around.

Reach for it when

  • Nothing new. New sign ups are closed
  • Existing users finishing an in flight migration or edge deployment

Do not reach for it when

  • You are a new customer with a bulk transfer. Use aws-data-transfer-terminal or an online copy service.
  • You need compute at a remote site. Use aws-outposts-family.
  • You want normal cloud storage. Use amazon-simple-storage-service.

One small example

A ship at sea collected sensor data on a device and the box was posted ashore on arrival.

How you pay

A per job device fee plus daily rental after a free window, plus shipping. The classic surprise was the daily charge while the device sat unused on a loading dock.
