AWS CodeArtifact

Developer Tools  ·  Advanced, most people never need it

A private store for the code libraries your team installs.

Picture it as

A company stockroom. Common parts are pulled in from the outside supplier once, and your own in house parts sit on the same shelves.

What it actually does

CodeArtifact hosts private npm, pip, Maven, NuGet and similar packages, and can also mirror public registries so builds do not break when a public package vanishes. Authentication uses a token that expires, up to 12 hours, so build scripts must fetch a fresh one. It supports fewer package formats than JFrog Artifactory.

Reach for it when

  • You publish internal libraries that must not be public
  • You want a cached copy of public packages so builds are repeatable
  • You already run builds in AWS and want package access controlled by IAM

Do not reach for it when

  • You only use public packages and builds are fine, this is extra work for nothing
  • You need Docker images, use ECR instead
  • You need a format it does not support, use Artifactory or GitHub Packages

One small example

An internal Python utility library that every team installs with pip, without it ever being published to PyPI.

How you pay

Per GB stored, per request, and per GB transferred out of the region. The request charges add up when many build agents install the same packages repeatedly.
