AWS Lambda

Compute  ·  Learn this early

Run a small piece of code without owning a server.

Picture it as

A taxi instead of a car. You pay for the trip, not for parking it all night.

What it actually does

You upload a function. AWS runs it when something triggers it, then shuts it down. Nothing to patch, nothing running idle. It sleeps between requests, so the first call after a quiet spell can be slower.

Reach for it when

  • Short jobs that run on an event
  • Traffic that comes in bursts
  • You do not want to manage a server at all

Do not reach for it when

  • Jobs that run longer than 15 minutes
  • Something that must respond instantly every single time

One small example

Someone uploads a photo, a function makes a thumbnail, then stops.

How you pay

Per request and per millisecond of run time. Nothing when idle.
