AWS Infrastructure Composer

Developer Tools  ·  Advanced, most people never need it

Draw your AWS setup on a canvas and get the config file out of it.

Picture it as

Sketching a floor plan by dragging furniture around, and the builder's drawing is produced from your sketch.

What it actually does

Renamed from AWS Application Composer in October 2024. You drag services onto a canvas in the console or in VS Code, connect them, and it writes a CloudFormation or SAM template. It also draws a diagram from an existing template, which is often the more useful direction. It covers a limited set of resource types well, and hand edits and canvas edits can fight each other.

Reach for it when

  • You are new to CloudFormation and want to see the shape of a template
  • You want a diagram of a template someone else wrote
  • You are sketching a small serverless app before writing code

Do not reach for it when

  • Your infrastructure is large or written in CDK, this will not help
  • You need full control over every property, write the template by hand

One small example

Dragging an API Gateway, a Lambda and a DynamoDB table onto the canvas and exporting a working SAM template.

How you pay

Free to use. You pay for whatever the generated template deploys, which is easy to underestimate from a picture.
