AWS FinOps Agent

Cost and Billing  ·  Advanced, most people never need it

An AI agent that watches your AWS bill, investigates cost spikes and answers cost questions in plain English.

Picture it as

A finance person who notices the bill jumped, finds out who changed what, and tells the right engineer.

What it actually does

AWS FinOps Agent is an agent you create in your own AWS account to monitor cost, investigate anomalies and surface savings. It reads cost and usage data from AWS Cost Explorer, listens for alerts from AWS Cost Anomaly Detection, pulls recommendations from Cost Optimization Hub and Compute Optimizer, and uses AWS CloudTrail to find the change that caused a spike. It then writes an investigation summary with a likely root cause and the owner, and can open a Jira ticket or post to Slack. Engineers can also just ask it questions such as why cost went up last month. You can upload context files, for example which account belongs to which team, so it answers in your own terms. Each agent is a separate instance with its own permissions, context, memory and integrations. It is in preview and starts in the US East N. Virginia region, so expect changes.

Reach for it when

  • A cost spike appears and nobody wants to dig through CloudTrail to find which change caused it
  • You want engineers to self serve cost answers instead of pinging the finance team
  • You want anomaly alerts to arrive as a Slack message or Jira ticket with a cause already attached, not just a number

Do not reach for it when

  • If your AWS bill is small and one person reads Cost Explorer once a month, this is more machinery than you need. Cost Explorer plus AWS Budgets is enough.
  • If you only want to be told when spend crosses a limit, AWS Budgets does that on its own.
  • It is in preview, so do not put a process that must not break on top of it yet.

One small example

Cost Anomaly Detection flags a 900 dollar jump overnight. The agent correlates it with CloudTrail, finds a team launched a large GPU instance and left it running, and posts that in Slack with the owner named, by the time people log in.

How you pay

Preview pricing should be checked on the AWS page before use. The data sources it reads, Cost Explorer, Cost Anomaly Detection and Compute Optimizer, are largely free or low cost on their own, so the agent's own charge is what to look at.
