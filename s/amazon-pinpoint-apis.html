Amazon Pinpoint APIs

Business Applications  ·  Advanced, most people never need it

The older set of Pinpoint APIs for customer messaging, most of which stop working in October 2026.

Picture it as

A phone line that is being switched off, with the useful calls moved to a new number.

What it actually does

Amazon Pinpoint was a service for talking to your customers by email, SMS, push and voice, with campaigns, journeys and analytics on top. AWS has announced end of support for Amazon Pinpoint on 30 October 2026. After that date the Pinpoint console and Pinpoint resources such as endpoints, segments, campaigns, journeys and analytics stop being available. The parts that survive are the sending APIs. AWS says the APIs for SMS, voice, mobile push, OTP and phone number validate are not affected, and those now live under AWS End User Messaging. So "Amazon Pinpoint APIs" today means two different things. The campaign and analytics APIs are going away. The message sending APIs continue under a new name.

Reach for it when

  • You already have an app calling Pinpoint APIs and need to plan the move before October 2026
  • You want to send SMS, push, OTP or voice from your own code, in which case you use AWS End User Messaging
  • You are checking which of your API calls survive the end of support date

Do not reach for it when

  • Do not start a new project on Pinpoint APIs. The service has an end of support date. For SMS, push, voice and OTP use AWS End User Messaging. For email use Amazon SES.
  • If you only send transactional email such as receipts and password resets, Amazon SES is the better fit and always was.
  • If you want marketing campaigns and customer journeys with a console, AWS no longer offers that here. You will need a third party tool.

One small example

A shopping app sends order updates by SMS and push. The sending calls keep working through AWS End User Messaging. The campaign that used to send a weekly offer from the Pinpoint console has to move somewhere else before October 2026.

How you pay

You pay per message sent, by channel, with the price depending on the country for SMS and voice. There is no charge for the API itself. Pinpoint campaign and analytics features carried their own charges, and those go away with the service.
