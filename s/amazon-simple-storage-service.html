Amazon Simple Storage Service

Storage  ·  Learn this early

A place to keep files, as many as you want.

Picture it as

An unlimited cupboard. You put a file in, you get a link to it.

What it actually does

S3 stores files, called objects, in buckets. It is built for very high durability. It is not a disk you can mount and edit in place. You put a whole file and get a whole file.

Reach for it when

  • Images, videos, PDFs, backups
  • Website files
  • Data before you analyse it

Do not reach for it when

  • A database. It cannot search inside your data.
  • A file share your server edits live. Use EFS.

One small example

All product photos for an online shop, served through CloudFront.

How you pay

Per GB stored per month, plus requests, plus data going out.
