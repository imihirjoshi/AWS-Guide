AWS Service Management Connector

Management and Governance  ·  Advanced, most people never need it

Retiring. It let ServiceNow or Jira users request and see AWS resources from their own ticket tool.

Picture it as

A hatch between two offices, now being bricked up.

What it actually does

This is being shut down. It closed to new customers on 31 March 2026 and support ends on 31 March 2027, after which it stops working. It was a plugin for ServiceNow, Jira Service Management and Jira Cloud that surfaced AWS Service Catalog products, AWS Config data, Security Hub findings and Support cases inside those tools. AWS now tells customers to use partner ITSM integrations or write their own with the SDK.

Reach for it when

  • Nothing new. Existing users should be planning their exit
  • Understanding an old diagram or runbook that mentions it
  • Deciding what replaces it before March 2027

Do not reach for it when

  • Do not start a new project on it. It is being switched off. Use a partner ITSM integration or build a direct SDK integration.
  • If you only need a self-service catalogue inside AWS, use AWS Service Catalog on its own, which is not affected.
  • If you want AWS events pushed into a ticket tool, EventBridge plus a webhook does that and is not going away.

One small example

A staff member used to raise a ServiceNow ticket for a test server and get an approved EC2 instance, and that path now needs rebuilding.

How you pay

The connector was free. You paid only for the AWS resources it created. The real cost now is the migration work before the 2027 cutoff.
