Amazon Managed Blockchain

Blockchain  ·  Advanced, most people never need it

Runs blockchain networks so you do not have to operate the nodes yourself.

Picture it as

Renting a seat at a shared ledger that several companies all write into, with someone else maintaining the room.

What it actually does

Two separate things sit under this name. One creates and runs a private Hyperledger Fabric network between named members. The other gives you access to public blockchain nodes, mainly Ethereum and Bitcoin, so you can read and write without running your own node. Very few business problems actually need a blockchain, and a shared database with good audit logging solves most of them.

Reach for it when

  • Several companies that do not trust each other must share one record
  • You need public chain node access without operating nodes

Do not reach for it when

  • Keeping an audit trail inside one company, an append only table with row level security is far simpler and cheaper
  • Anything where one organisation owns the data, a normal database is the honest answer

One small example

Three logistics firms record container handovers on one shared ledger that none of them alone can rewrite.

How you pay

Per node hour and per GB of data written, or per request for node access. Idle nodes keep billing, which is the usual surprise.
