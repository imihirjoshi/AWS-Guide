Amazon AppFlow

Application Integration  ·  Advanced, most people never need it

A managed way to move data between business apps like Salesforce or SAP and AWS, without writing the plumbing.

Picture it as

A courier between two offices that do not speak the same language. You say what to send and how often, and it goes.

What it actually does

Amazon AppFlow is a real AWS service. It copies data between software as a service apps and AWS. On one side you have apps like Salesforce, SAP, ServiceNow, Slack or Zendesk. On the other side you have AWS stores like Amazon S3 and Amazon Redshift. You set up a flow: pick the source, pick the target, map the fields, and pick when it runs. It can run on a schedule, on an event in the source app, or when you press run. It can filter rows, mask or drop fields, and combine data before it lands. Traffic can stay off the public internet using AWS PrivateLink. You do not build or run any connector code yourself.

Reach for it when

  • Pulling Salesforce or SAP records into Amazon S3 for reporting
  • Feeding SaaS data into a data lake or warehouse on a schedule
  • Pushing AWS data back out into a business app so sales or support teams see it
  • Small to medium data syncs where you do not want to maintain custom API code

Do not reach for it when

  • Not for moving data between AWS databases. AWS Database Migration Service or AWS Glue fit better.
  • Not for app to app data that is already in your own systems and needs heavy transformation. AWS Glue gives more control.
  • Not for real time streaming. AppFlow runs flows, it is not a stream.
  • Not useful if your source app has no AppFlow connector. Check the supported list first, or write your own integration.
  • If you need complex joins or business logic in the middle, do that after landing the data, not in AppFlow.

One small example

A company copies new Salesforce opportunities into Amazon S3 every hour, then reports on them in Amazon Athena next to their billing data.

How you pay

You pay per flow run, plus per GB of data processed. Prices differ by connector type. There is no monthly fee for keeping a flow that does not run. Check the AppFlow pricing page.
