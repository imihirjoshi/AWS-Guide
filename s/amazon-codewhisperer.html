Amazon CodeWhisperer

AI and Machine Learning  ·  Common, learn when you need it

The old name for AWS code autocomplete, now folded into Amazon Q Developer.

Picture it as

A shop sign that was painted over. Same shop, new name.

What it actually does

CodeWhisperer suggested code in your editor as you typed. On 30 April 2024 it became part of Amazon Q Developer, which kept the inline suggestions and security scans and added chat, agents and AWS troubleshooting. The name CodeWhisperer no longer exists as a product, so if a tutorial or exam question uses it, read it as Q Developer.

Reach for it when

  • Reading old documents or exam material that still uses the name

Do not reach for it when

  • Anything you are building today, install Amazon Q Developer instead
  • Broad agentic coding work, most people use a dedicated coding agent

One small example

An old blog post tells you to enable CodeWhisperer in VS Code, and the plugin you actually install is Amazon Q.

How you pay

Nothing, it no longer exists. Q Developer has a free tier and a paid per user per month tier.

Usually sits next to

Amazon QAn AI assistant for AWS work, split into one for developers and one for business users.
