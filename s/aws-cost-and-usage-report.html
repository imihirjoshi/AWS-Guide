AWS Cost and Usage Report

Cost and Billing  ·  Common, learn when you need it

It drops a giant spreadsheet of every line of your AWS bill into an S3 bucket.

Picture it as

An itemised phone bill, except every call is listed hour by hour, so the file is far too big to read by eye.

What it actually does

It is the most detailed billing data AWS gives you, one row per resource per hour, delivered as compressed files a few times a day. You are meant to query it with Athena or load it into a data tool, not open it. The newer version, CUR 2.0, is created through the Data Exports console and has a cleaner, more stable column layout.

Reach for it when

  • You need exact per-resource costs for chargeback
  • You are building your own cost dashboard
  • Cost Explorer does not slice the data the way you need

Do not reach for it when

  • You just want to see where the money went, Cost Explorer already shows that with no setup
  • You want alerts, use AWS Budgets

One small example

A finance team queries the report in Athena to find every S3 bucket that cost more than 100 dollars last month.

How you pay

The report itself is free. You pay for the S3 storage and for every Athena query you run against it, and the files get big fast.
