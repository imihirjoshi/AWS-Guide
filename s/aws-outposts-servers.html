AWS Outposts servers

Compute  ·  Advanced, most people never need it

A single AWS server box you put in a shop, clinic or factory.

Picture it as

A vending machine AWS drops off, refills and services, but it lives in your shop.

What it actually does

This is the small version of Outposts. A 1U or 2U server arrives, you or a contractor rack it, and AWS provisions it remotely. It runs far fewer services than the rack, mainly EC2, ECS and local storage, and there is no local block storage service or database service.

Reach for it when

  • A retail store needs compute on site when the internet drops
  • A factory floor needs fast local processing of sensor data
  • Hundreds of small sites need the same setup managed centrally

Do not reach for it when

  • If you have real data centre space and need databases or large capacity, use the Outposts rack.
  • If you just need to process data on a small device at the edge, aws-iot-greengrass is far cheaper and simpler.
  • If latency is fine, use a normal Region with amazon-ec2.
  • Very few teams need this.

One small example

A supermarket chain puts one 1U Outposts server in each store to run checkout software that must keep working offline.

How you pay

Per server, on a 3 year commitment, paid up front or monthly. Capacity is fixed, so you pay the same whether the box is busy or idle.
