AWS Resource Access Manager

Security and Identity  ·  Advanced, most people never need it

Lets one AWS account share a specific resource with another account.

Picture it as

Giving a neighbour a key to your garage. They can use that one space, not the whole house.

What it actually does

Known as RAM. It shares certain resource types across accounts, most often VPC subnets, Transit Gateways, Route 53 resolver rules and License Manager configurations. The other account uses the resource as if it were theirs, while you keep ownership and pay for it. Only some resource types can be shared, and it works best inside one AWS Organization.

Reach for it when

  • Many accounts using one shared network
  • Sharing a Transit Gateway across the company
  • Central DNS resolver rules for every account

Do not reach for it when

  • Sharing files or data, use an S3 bucket policy
  • Giving someone access to act in your account, use an IAM cross account role

One small example

The network account shares its private subnets, so each team's account launches workloads into the shared VPC.

How you pay

Free. The owning account keeps paying for the shared resource, which is the part that catches out billing.
