Basics / Services / Storage

Amazon S3 on Outposts

Storage  ·  Advanced, most people never need it

Gives you S3 buckets on AWS hardware sitting in your own building.

Picture it as

Having the same brand of filing cabinet at home as the one at head office.

What it actually does

It is S3 buckets running on an Outposts rack in your data centre, so the data never leaves your premises. Your code uses the normal S3 API through an access point. The limits matter, there is only one storage class, capacity is fixed by the hardware you bought, and features like versioning and cross region replication are not the same as in a Region.

Reach for it when

  • A law or contract says the data must stay in your building
  • An application on the Outpost needs local storage with very low latency
  • You want one S3 style codebase across cloud and on premises

Do not reach for it when

  • You have no regulatory or latency reason to keep data local. Plain amazon-simple-storage-service is cheaper and has far more features.
  • You need shared file access rather than object storage. Use amazon-efs style file storage on the Outpost.
  • You just want a one off bulk transfer. That is not what this is.

One small example

A hospital keeps scan images in an S3 bucket on an Outpost rack in its own basement.

How you pay

You pay for the Outpost rack up front or over a term, and the storage capacity is bought with it. The surprise is that you pay for the whole capacity whether or not you fill it.
