Amazon CodeGuru

AI and Machine Learning  ·  Advanced, most people never need it

Reviewed your code and found slow spots in running apps, and is now mostly closed.

Picture it as

A picky senior colleague who read your pull requests and timed your app with a stopwatch, who has since left.

What it actually does

Two parts. Reviewer commented on pull requests. Profiler watched a running app and showed which lines burned CPU. As of November 2025 you cannot add new repositories to Reviewer, and AWS points people to Amazon Q Developer for reviews and Amazon Inspector for security scanning. Profiler and the security scanning bits live on under other names. Treat CodeGuru as a service on the way out.

Reach for it when

  • You already have existing repository associations running
  • You want CPU profiling of a live Java or Python app

Do not reach for it when

  • New code review setups, use Amazon Q Developer or a normal linter and human review
  • Security scanning, use Amazon Inspector

One small example

A team learned one logging call in a hot loop was eating a quarter of their CPU.

How you pay

Reviewer charged per hundred lines scanned per month, Profiler per sampled hour. Large monorepos made the line count bill jump.
