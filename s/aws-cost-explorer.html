AWS Cost Explorer

Cost and Billing  ·  Learn this early

Shows where your AWS money is going.

Picture it as

A bank statement with charts, so you can see what you actually spend on.

What it actually does

Cost Explorer breaks the bill down by service, tag and time, and forecasts next month. Tag everything from day one or the breakdown is useless. Set a budget alert on day one too.

Reach for it when

  • Always. From the first day.

One small example

Spotting that a forgotten test server has cost 4,000 rupees this month.

How you pay

The console view is free. The API has a small per request charge.

Usually sits next to

AWS BudgetsIt emails you when your AWS spending passes a number you picked.AWS Trusted AdvisorChecks your account and suggests fixes.
