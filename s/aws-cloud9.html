AWS Cloud9

Developer Tools  ·  Advanced, most people never need it

A code editor that ran in your browser, now closed to new customers.

Picture it as

A shared workshop that stopped taking new members. The people already inside can keep working, but nobody new gets a key.

What it actually does

Cloud9 was a browser based IDE with a terminal attached to an EC2 machine. AWS stopped accepting new customers in mid 2024 and is not adding features. Existing users still have it. If you want a browser terminal today, use CloudShell, and for a full editor use VS Code on your own machine or a remote dev environment.

Reach for it when

  • You are an existing Cloud9 user and it still works for you
  • You are reading old tutorials and need to know why the button is missing

Do not reach for it when

  • You want a quick terminal in the browser, use CloudShell
  • You want a real IDE, use VS Code locally with the AWS Toolkit

One small example

An old workshop tells you to open a Cloud9 environment, and your account has no option to create one.

How you pay

You paid for the EC2 instance behind it, not the editor. People were billed for idle environments they forgot to stop.
