AWS Chatbot

Management and Governance  ·  Common, learn when you need it

Sends AWS alerts into Slack or Microsoft Teams, and lets you run some commands from the chat.

Picture it as

A pager that posts into the team group chat instead of buzzing one person.

What it actually does

It was renamed to Amazon Q Developer in chat applications in February 2025. The API, the console URL and the IAM names are still chatbot, so you will see both names. Alarms and events go to an SNS topic, and it posts them to a channel. You can also type read only AWS commands in chat. It is not a conversational bot for your customers.

Reach for it when

  • Getting CloudWatch alarms into a team channel
  • Letting on-call check a resource without opening the console
  • Posting deploy or budget events to chat

Do not reach for it when

  • Building a chatbot for your own users, use Amazon Lex or Amazon Bedrock
  • Serious incident paging with escalation, use PagerDuty or similar

One small example

A CloudWatch alarm on database CPU posts to the #ops Slack channel, and someone types a command there to check the instance.

How you pay

The service is free. You pay for the SNS messages and CloudWatch behind it, which is small.
