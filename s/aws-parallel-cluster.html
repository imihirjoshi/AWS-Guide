AWS Parallel Cluster

Compute  ·  Advanced, most people never need it

Sets up a cluster of machines that run scientific jobs in a queue.

Picture it as

Hiring a shift manager who opens extra counters when the queue grows and closes them when it empties.

What it actually does

It is an open source command line tool, not a hosted service. You give it a config file and it builds the head node, the Slurm scheduler, the shared file system and the compute nodes. You still own and operate the cluster, including patching and upgrades.

Reach for it when

  • Running engineering simulations or genomics pipelines
  • Moving an existing on-site Slurm cluster to AWS
  • You want machines to start only while jobs are waiting

Do not reach for it when

  • AWS Parallel Computing Service (PCS) is the newer managed Slurm option. Pick that if you do not want to run the cluster yourself.
  • For ordinary batch work that is not HPC, aws-batch or aws-step-functions is simpler.
  • If your work is containers, use amazon-elastic-kubernetes-service.
  • Nobody outside HPC and research computing needs this.

One small example

A drug research team submits 2000 molecule simulations; the cluster grows to 500 instances, then shrinks back to zero.

How you pay

The tool is free. You pay for the EC2 instances, the shared storage and the network. The surprise is the head node and shared file system run 24/7 and cost money even with no jobs.
