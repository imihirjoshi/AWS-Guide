AWS Nitro Enclaves

Compute  ·  Advanced, most people never need it

A sealed side room on your server where secret data can be processed and nobody, not even you, can look in.

Picture it as

A bank's night safe drop slot. Things go in through one narrow opening, nothing else reaches inside, not even the branch staff.

What it actually does

An enclave is an isolated virtual machine carved out of an EC2 instance, with no network, no persistent storage and no shell access. The only way in or out is a local secure channel from the parent instance. It can prove what code it is running through attestation, and KMS can be told to release a key only to that proven code. This is a specialist tool, most teams never need it.

Reach for it when

  • Processing card numbers or health records where even admins must be excluded
  • Holding private keys for signing, with proof of the code using them
  • Regulated multi-party data where each side must not see the other's raw data

Do not reach for it when

  • Ordinary secret storage, use AWS Secrets Manager or Parameter Store
  • Just encrypting data, use KMS on its own
  • Any workload needing disk or direct network access, it has neither

One small example

A payments firm decrypts card data only inside an enclave, so its own engineers can never read a full card number.

How you pay

No extra charge for the enclave. You pay for the parent EC2 instance, which must be large enough to donate CPU and memory to the sealed room, so you buy capacity you cannot otherwise use.
