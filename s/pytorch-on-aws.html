PyTorch on AWS

AI and Machine Learning  ·  Learn this early

Not a service, just the many ways to run the PyTorch framework on AWS.

Picture it as

A shop's sign saying we sell shoes. The sign is not itself a shoe.

What it actually does

PyTorch is open source software from the PyTorch Foundation for building and training neural networks. PyTorch on AWS is a marketing page, not something you can switch on or get a bill for. What it points to is real, the Deep Learning AMIs and Containers, SageMaker AI training jobs, GPU and Trainium instances, and the Neuron plugin. If you are looking for a service to enable, there is not one.

Reach for it when

  • You are deciding where to run PyTorch training or inference on AWS
  • You want the AWS-maintained builds rather than installing everything yourself

Do not reach for it when

  • Do not look for a PyTorch service to turn on, pick SageMaker AI, EC2 or ECS and run PyTorch there
  • If you only want to call an existing model, you do not need PyTorch at all, use Amazon Bedrock

One small example

A developer reads the page, then launches a Deep Learning Container on SageMaker AI to train a PyTorch model.

How you pay

Nothing for PyTorch, it is free and open source. You pay only for whatever compute and storage you run it on, and GPU hours are the bulk of it.
