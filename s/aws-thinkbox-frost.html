AWS Thinkbox Frost

Media  ·  Advanced, most people never need it

A 3ds Max plugin that turns clouds of particles into a solid surface you can render.

Picture it as

Taking a bowl of tiny beads and shrink wrapping them, so it looks like one smooth blob of liquid instead of beads.

What it actually does

Frost is a mesher for 3ds Max: it builds geometry around particle simulations so splashes, mud, snow or crowds of objects can be rendered. It is a niche artist tool with nothing to do with cloud computing. AWS made it free in 2022 and published the source on GitHub, but has not updated it since; a community developer maintains builds for newer 3ds Max versions. Almost nobody outside 3ds Max VFX work needs it.

Reach for it when

  • 3ds Max artists meshing fluid or particle simulations
  • Scattering geometry over particle positions
  • Existing pipelines already built on Frost

Do not reach for it when

  • Any non 3ds Max software, use that package's own mesher such as Houdini's VDB tools
  • Anything to do with AWS infrastructure, it is a desktop plugin
  • New work, be aware AWS is not developing it

One small example

An artist turns a 3ds Max water splash simulation into a renderable mesh for a drinks advert.

How you pay

Free, with no AWS account needed. The cost is the 3ds Max licence and the machines you render on.
