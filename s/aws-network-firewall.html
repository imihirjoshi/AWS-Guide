AWS Network Firewall

Security and Identity  ·  Advanced, most people never need it

A firewall that inspects traffic going in and out of your private network in AWS.

Picture it as

A guard at the estate gate who checks where each van is going, not just whether it has a pass.

What it actually does

Network Firewall is a managed, stateful firewall for a VPC. It can filter by domain name, match Suricata intrusion detection rules, and block outbound traffic to places you did not approve. Security groups and network ACLs already do simple allow and deny far more cheaply, so this earns its place mainly when you need deep inspection or outbound domain control. Getting the routing right, with traffic forced through firewall endpoints, is the hard part.

Reach for it when

  • You must control which domains your servers can reach outbound
  • A compliance rule demands intrusion detection on network traffic
  • A central inspection VPC for many accounts

Do not reach for it when

  • For ordinary port and source rules, security groups are free and enough
  • For filtering HTTP attacks on a public web app, use WAF
  • For blocking DNS lookups only, Route 53 Resolver DNS Firewall is much cheaper

One small example

A regulated workload may only call api.stripe.com outbound, and Network Firewall drops every other destination.

How you pay

An hourly charge per firewall endpoint in each availability zone, plus a charge per gigabyte inspected. The per-zone hourly fee adds up before you pass any traffic.
