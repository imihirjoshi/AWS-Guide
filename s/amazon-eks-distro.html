Amazon EKS Distro

Containers  ·  Advanced, most people never need it

The exact Kubernetes build AWS itself runs, handed to you as open source.

Picture it as

Buying the same flour and yeast the bakery uses, then baking the bread yourself.

What it actually does

EKS Distro is a set of tested Kubernetes binaries and container images on GitHub, with AWS security patches. It is parts, not a product. It does not install, run or upgrade anything for you, and there is no console and no support ticket.

Reach for it when

  • You already have your own cluster build process
  • You want versions patched after upstream support ends
  • Building a Kubernetes product of your own

Do not reach for it when

  • If you want clusters created and managed for you on your hardware, use EKS Anywhere.
  • If you want a managed cluster, use amazon-elastic-kubernetes-service.
  • This is for platform teams. Almost no application team should touch it.

One small example

A platform team builds its own cluster images from EKS Distro so its on-site clusters match the AWS ones.

How you pay

Free. You pay only for wherever you run it.
