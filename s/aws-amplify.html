AWS Amplify

Front End Web and Mobile  ·  Common, learn when you need it

The quickest way to put a web or mobile front end online.

Picture it as

A ready made kitchen fitted in a day, instead of building one.

What it actually does

Amplify hosts your front end, connects to GitHub and deploys on every push. It can also generate a backend with auth, API and storage. Great to start, restrictive once your needs grow.

Reach for it when

  • React, Next.js or Vue front ends
  • Quick prototypes and MVPs

Do not reach for it when

  • Complex custom backends.

One small example

Pushing to GitHub and the site is live two minutes later.

How you pay

Per build minute and per GB served, with a free tier.
