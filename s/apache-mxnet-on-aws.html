Apache MXNet on AWS

AI and Machine Learning  ·  Advanced, most people never need it

AWS support for an old deep learning framework that is no longer maintained.

Picture it as

A car model the maker stopped producing. Some still run, but no parts are being made.

What it actually does

MXNet was an open source deep learning framework AWS backed heavily around 2016 to 2020, with prebuilt images, SageMaker containers and Deep Learning AMIs. Apache moved MXNet to the Attic in 2023, meaning it is retired with no further releases, and AWS has dropped it from newer Deep Learning Containers. It still turns up in old AWS tutorials and exam material. Nobody should start a new project on it.

Reach for it when

  • Keeping an existing MXNet model alive long enough to port it

Do not reach for it when

  • Any new model, use PyTorch, which is what almost everyone uses now
  • Serving an old MXNet model long term, export it to ONNX and run it somewhere supported

One small example

An old SageMaker notebook imports mxnet and fails on a current container image.

How you pay

The framework was free. You only ever paid for the EC2 or SageMaker compute under it.
