AWS License Manager

Management and Governance  ·  Advanced, most people never need it

Keeps count of software licences you own so you do not go over what you paid for.

Picture it as

A library ticket system. Only so many copies exist, so it tracks who has one out.

What it actually does

You describe a licence rule, such as 100 Windows Server cores, and it counts usage across accounts and can block launches that would break the limit. It also manages bring your own licence hosts and user based subscriptions for things like Office on AppStream. Most people only meet it because a vendor audit or a Microsoft agreement forced them to.

Reach for it when

  • Bringing your own Windows or Oracle licences to AWS
  • Proving licence compliance in an audit
  • Stopping teams launching more licensed instances than allowed

Do not reach for it when

  • Everything running on open source or AWS supplied licences, you do not need it
  • Tracking SaaS seats like Slack or Figma, it does not do that

One small example

A launch of an eleventh Oracle instance is blocked because the rule says you own ten.

How you pay

The core tracking is free. User based subscriptions carry a per user monthly charge, and dedicated hosts for bring your own licence are the expensive part.
