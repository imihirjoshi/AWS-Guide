Open 3D Engine

Games  ·  Advanced, most people never need it

A free 3D game and simulation engine you download and build with.

Picture it as

A free workshop full of tools. Nobody charges rent, but you still have to build the furniture.

What it actually does

O3DE is not an AWS service. It is open source software under the Linux Foundation, built from the code of the retired AWS Lumberyard. AWS is one member of the foundation, not the owner. It is far less used than Unreal or Unity, so tutorials, assets and hiring are thin.

Reach for it when

  • You want a 3D engine with no royalties and full source
  • Robotics simulation, where its ROS support is used
  • You need to change engine internals

Do not reach for it when

  • For most games, Unreal or Unity has a far bigger ecosystem. Pick those unless royalties or source access are the deciding issue.
  • There is nothing to buy or switch on in the AWS console.
  • If you need hosted game servers, that is Amazon GameLift Servers, a different thing.

One small example

A robotics team simulates a warehouse robot in O3DE before running the same code on real hardware.

How you pay

Free, with no royalties. You pay only for whatever machines you run it on.

Amazon EC2A computer you rent in Amazon's data centre.Amazon Simple Storage ServiceA place to keep files, as many as you want.
