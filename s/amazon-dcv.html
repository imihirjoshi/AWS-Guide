Amazon DCV

Compute  ·  Advanced, most people never need it

Lets you use a graphics heavy desktop that is running somewhere else.

Picture it as

A very good live video link to a computer in another room, with your mouse and keyboard attached.

What it actually does

Amazon DCV is the renamed NICE DCV, the remote display protocol AWS bought in 2016. It streams the screen of a remote Linux or Windows machine to a laptop or browser. It is software you install, not a managed service, and it is the same protocol underneath WorkSpaces and AppStream.

Reach for it when

  • A designer needs a CAD or 3D app that will not run on a laptop
  • Viewing simulation results that live next to the data
  • Giving engineers access to a shared GPU workstation

Do not reach for it when

  • If you want a finished managed desktop, use amazon-workspaces instead of building your own.
  • For plain server admin, SSH or Systems Manager is enough.
  • If the app is a normal web app, none of this is needed.

One small example

An architect opens a 40 GB building model on a GPU instance in Mumbai and works on it from a thin laptop.

How you pay

No charge for the DCV server when it runs on an EC2 instance. You pay the normal EC2 and GPU cost. Running DCV outside AWS needs a paid licence, which catches people out.

Usually sits next to

Amazon EC2A computer you rent in Amazon's data centre.Amazon WorkSpacesGives each person a Windows or Linux desktop they open from any device.
