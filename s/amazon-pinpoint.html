Amazon Pinpoint

Business Applications  ·  Advanced, most people never need it

A marketing messaging service that AWS is closing down.

Picture it as

A mailroom that still delivers, but the landlord has posted the date it shuts, so nobody moves in.

What it actually does

It combined message sending with audience segments, campaigns, journeys and analytics. AWS stopped taking new customers in May 2025 and support ends on 30 October 2026, after which the console, segments, campaigns, journeys and analytics stop working. The sending channels live on as AWS End User Messaging, and confusingly the API is still named pinpoint. If you are on it, plan the move now.

Reach for it when

  • Nothing new
  • Only for planning an exit if you already run campaigns on it

Do not reach for it when

  • New campaign and journey work, use Braze, Iterable, Klaviyo or Amazon Connect outbound campaigns
  • Plain SMS, push or voice sending, use AWS End User Messaging
  • Email, use Amazon SES

One small example

A retailer exports its Pinpoint segments and journey definitions and rebuilds them in Braze ahead of the October 2026 cutoff.

How you pay

Was per targeted endpoint per month plus per message. The migration effort, not the bill, is the cost that matters now.
