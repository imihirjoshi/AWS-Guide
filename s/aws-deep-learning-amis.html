AWS Deep Learning AMIs

AI and Machine Learning  ·  Common, learn when you need it

A ready-made server image with the AI tools already installed.

Picture it as

Buying a kitchen that already has the oven, pans and knives fitted, instead of an empty room you have to kit out yourself.

What it actually does

An Amazon Machine Image, a template you launch an EC2 server from, that comes with PyTorch, GPU drivers, CUDA and the usual Python stack preinstalled and tested together. It saves you a day of driver pain. It is not a managed service, so once the server is running you patch it, secure it and shut it down yourself, and the running server costs the same as any GPU instance.

Reach for it when

  • You want a GPU box for training or experiments and do not want to install drivers
  • You need full control of the machine, SSH access included
  • You are testing on one instance before moving to something bigger

Do not reach for it when

  • If you want training runs, tuning and endpoints managed for you, use SageMaker AI instead
  • If you ship in containers, use Deep Learning Containers on ECS or EKS instead of a hand-kept server

One small example

A researcher launches a g6 GPU instance from the Deep Learning AMI, fine-tunes a small model overnight, and terminates it in the morning.

How you pay

The AMI is free. You pay the normal EC2 GPU hourly rate plus storage, and the storage keeps billing after you stop the instance. Forgetting to terminate a GPU box is the classic bill shock.
